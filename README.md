# Quantum Chemistry Analyzer

A single-page web app for ML-assisted quantum chemistry analysis.  
Enter any chemical compound name → get structured property data + a 2D molecular diagram, powered by the Anthropic API.

---

## Stack

| Layer     | Choice                         | Reason                                      |
|-----------|--------------------------------|---------------------------------------------|
| Backend   | **FastAPI** + Uvicorn          | Async, auto-docs at `/docs`, typed routes   |
| AI        | **Anthropic API** (claude-sonnet-4) | Structured JSON chemistry data + coordinates |
| Frontend  | Vanilla HTML/CSS/JS (no framework) | Zero build step, fully portable             |
| Diagram   | **Custom SVG renderer** (built-in) | No extra deps; handles bond orders + colors |
| Cache     | In-memory Python dict          | Session-scoped, zero config                 |

## Quick Start

### 1. Clone / copy the project

```
quantum_chem_app/
├── main.py
├── requirements.txt
├── README.md
└── static/
    └── index.html
```

### 2. Install dependencies

```bash
cd quantum_chem_app
pip install -r requirements.txt
```

### 3. Set your Anthropic API key

```bash
# macOS / Linux
export ANTHROPIC_API_KEY=sk-ant-...

# Windows (PowerShell)
$env:ANTHROPIC_API_KEY="sk-ant-..."
```

### 4. Run the server

```bash
python main.py
# or, with hot-reload during development:
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

### 5. Open the app

```
http://localhost:8000
```

API docs (auto-generated by FastAPI):
```
http://localhost:8000/docs
```

## API Endpoints

| Method | Path                  | Description                                              |
|--------|-----------------------|----------------------------------------------------------|
| GET    | `/`                   | Serves `static/index.html`                               |
| GET    | `/component/{name}`   | Returns compound metadata + atom/bond arrays (JSON)      |
| GET    | `/diagram/{name}`     | Returns 2D diagram atom/bond data (JSON)                 |
| GET    | `/cache/status`       | Shows number of cached entries and keys                  |
| GET    | `/cache/clear`        | Clears the session cache                                 |

## Architecture

```
Browser
  │  POST/GET (fetch API)
  ▼
FastAPI (main.py)
  ├── GET /component/{name}
  │     ├── Check _cache dict
  │     └── Call Anthropic API → structured JSON → cache → return
  ├── GET /diagram/{name}
  │     ├── Check _cache (uses component atoms if already fetched)
  │     └── Call Anthropic API → atom/bond coords → cache → return
  └── Serve static/index.html

Browser JS
  ├── Fetches /component/{name}  → renders props grid
  └── Fetches atoms/bonds        → renderMolecule() → SVG
```

## Phased Roadmap

### ✅ Phase 1 — MVP (current)
- Input field + analyze button
- `/component/{name}` → AI-powered property data (20+ fields)
- `/diagram/{name}` → AI-generated 2D atom coordinates
- Custom SVG renderer (single/double/triple/aromatic bonds, per-element colors)
- In-memory session cache
- Error handling with user-visible messages
- Example chips (caffeine, glucose, aspirin…)

### Phase 2 — Enhancements
- **Persistent cache**: swap `_cache` dict for `diskcache` or SQLite (`shelve`) so data survives restarts
- **RDKit integration**: `pip install rdkit` for local structure generation (faster, no API call for common molecules)
- **3D viewer**: add `3Dmol.js` or `Speck.js` for a toggleable 3D view alongside the 2D diagram
- **Export**: download SVG diagram or copy JSON data to clipboard
- **Search history**: localStorage-backed list of recent queries

### Phase 3 — Production
- **Auth**: simple API-key header check on backend endpoints
- **Rate limiting**: `slowapi` middleware to prevent API abuse
- **Persistent DB**: PostgreSQL/SQLite with SQLAlchemy for multi-user caching
- **PubChem fallback**: try `https://pubchem.ncbi.nlm.nih.gov/rest/pug` first for known compounds, Anthropic only for unknowns
- **CI/CD**: Dockerfile + GitHub Actions for deploy to Fly.io / Railway

## Customization

### Swap in Flask (optional)

Replace `main.py`'s FastAPI imports with:

```python
from flask import Flask, jsonify, send_from_directory
app = Flask(__name__, static_folder='static')

@app.route('/component/<name>')
def get_component(name): ...
```

FastAPI is recommended (async, auto-docs), but the logic is identical.

### Add local molecule data

Edit the `_cache` dict pre-population at the bottom of `main.py`:

```python
_cache["comp:water"] = {
    "name": "Water", "formula": "H2O", ...
    "atoms": [{"symbol":"O","x":0,"y":0}, {"symbol":"H","x":1,"y":0.8}, ...],
    "bonds": [{"from":0,"to":1,"order":1}, ...]
}
```

## Troubleshooting

| Symptom | Fix |
|---|---|
| `502 ANTHROPIC_API_KEY not set` | `export ANTHROPIC_API_KEY=sk-ant-...` |
| `401 Invalid key` | Check key is active at console.anthropic.com |
| Diagram is empty | The AI may not have returned atom coords — try searching again |
| Slow first response | Normal — AI generates full JSON structure; subsequent hits are cached |
